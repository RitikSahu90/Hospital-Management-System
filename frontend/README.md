# 🏥 Hospital Management System - Frontend

A modern and responsive Hospital Management System Frontend built using **React**, **TypeScript**, **Vite**, and **Material UI**. The application provides an intuitive user interface for managing hospital operations such as patients, doctors, appointments, billing, pharmacy, laboratory, and settings.

---

## 📌 Project Overview

The Hospital Management System (HMS) is designed to simplify and digitize hospital management processes. This frontend application provides an easy-to-use dashboard and management interfaces while being fully prepared for backend API integration.

# ⚡ Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the frontend directory

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
